Value × Complexity Map
Value–to–Complexity (V–C) = Total Value − (Average Complexity × 2.5), where Average Complexity is the 0–4 mean of Business & Technical. This is not a prioritization rank — it shows how a project’s average complexity adjusts its value. Total Value stands on its own; the map shows the adjustment. Tunable.

Value-to-Complexity map value × complexity

Bands are diagonal: V–C = Value − (Complexity penalty). A high-value project stays in a top band even at higher complexity — the value outweighs the penalty. Axes run 0–100 in steps of 25.
